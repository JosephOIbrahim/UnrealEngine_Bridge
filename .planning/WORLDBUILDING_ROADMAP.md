# World-Building Capability Roadmap — UnrealEngine_Bridge

> Generated by a 20-agent orchestrated scan (4 understand · 8 discipline lenses · 8 feasibility verifiers).
> 48 proposals → 8 verified feasible against real UE5.7 editor-Python API. All clone the proven
> `scene.py`/`actors.py` codegen idiom (sanitize → f-string → `execute_python` → `RESULT:` JSON).
>
> **Mechanism note:** the f-string codegen path is NOT AST-sandboxed (only `python_exec.py` runs
> `validate_python_code`), and none of these touch `BLOCKED_*` — so the sandbox is a non-issue. The
> real constraints are the **10s RESULT poll timeout**, the **single `RESULT:` line** return, and **no
> state between calls**.

## The keystone insight

**Spatial reasoning is the connective tissue.** Today Claude places every actor at a blind absolute Z
with no sense of ground, volume, or collision. Four independent disciplines (scene-understanding,
terrain, foliage, layout) converged on this as their #1 prerequisite. Build it first; it unblocks
the rest.

---

## Tier 1 — Keystone + quick wins (build first)

### 1. Spatial reasoning foundation  ·  `spatial.py` (new module)  ·  M · transformative · FEASIBLE
Tools: `ue_ground_trace`, `ue_snap_to_ground`, `ue_spatial_query`, `ue_measure`
- **Unlocks:** "sit the cabin flush on that slope", "is there a 4m clearing for the statue", "how big
  is the village footprint", drape/settle props on terrain.
- **API:** `SystemLibrary.line_trace_single(world, start, end, TraceTypeQuery.TRACE_TYPE_QUERY1, False, [], DrawDebugTrace.NONE, True)`;
  world via `UnrealEditorSubsystem().get_editor_world()`; `actor.get_actor_bounds(False)` (already
  proven at `actors.py:212`); align via `MathLibrary.make_rot_from_z(impact_normal)`.
- **Gotchas:** Python binding returns `HitResult`-or-`None` (test `if hit:`, do NOT unpack a tuple);
  trace from `origin.z + extent.z + pad` and ignore self or it self-hits; Visibility channel misses
  no-collision proxies (param the channel, default WorldStatic); snap Z must add the actor's
  bbox-bottom offset or it floats/sinks; clearance query is O(n²) — cap actor count.

### 2. Time-of-Day Atmosphere Rig  ·  `lighting.py`  ·  M · transformative · FEASIBLE
Tools: `ue_setup_sky_atmosphere`, `ue_set_time_of_day`
- **Unlocks:** collapses hand-spawning 6 actors (DirectionalLight, SkyAtmosphere, SkyLight,
  ExponentialHeightFog, VolumetricCloud, PostProcessVolume) + 30 blind property writes into ONE verb:
  "give me an overcast 7am dawn." Sun azimuth/elevation, atmosphere-sun linkage, fog, clouds, exposure.
- **API:** `EditorActorSubsystem.spawn_actor_from_class` (idempotent — reuse if present);
  `set_editor_property` on components; sun pitch = -elevation.
- **Gotcha:** `SkyLight.recapture_sky()` is a METHOD call (not a property) and MUST run AFTER the
  atmosphere is configured, or ambient bounce won't match the sky.

### 3. Mood / Look-Dev Preset Library  ·  `lighting.py`  ·  M · high · FEASIBLE
Tools: `ue_apply_mood_preset`, `ue_blend_mood_presets`, `ue_list_mood_presets`
- **Unlocks:** directing in nouns — "golden hour", "blade-runner noir", "misty horror morning". Each
  preset = coordinated sun+fog+cloud + full `PostProcessSettings` color grade (temp, saturation,
  contrast, shadow/mid/highlight tint, bloom, vignette, grain).
- Builds directly on #2's rig. Preset values come from a server-side dict (never hit the sanitizer).

## Tier 2 — High-leverage verbs

### 4. Material graph authoring  ·  extend `materials.py`  ·  M · transformative · FEASIBLE
Tools: `ue_create_material_graph`, `ue_add_material_expression`, `ue_connect_material_nodes`
- **Unlocks:** real shaders, not just 3 baked constants — texture-sampled albedo/normal/roughness, UV
  tiling/panning (water/lava/wind), height-blend, Fresnel rim, triplanar, vertex-color masks.
- **API:** `MaterialEditingLibrary.create_material_expression(material, unreal.MaterialExpression<Type>, x, y)`
  + `connect_material_expressions(from, from_out_name, to, to_input_name)`.
- **Gotcha:** node inputs are addressed by NAME, not index ("A"/"B"/"Alpha" for Lerp, "Coordinate"
  for Panner, "" for default) — the JSON edge spec must carry the input name string.

### 5. Real transform keyframing  ·  finish `sequencer.py` stub  ·  M · transformative · FEASIBLE
Tools: `ue_add_keyframe` (currently a not-implemented stub), `ue_add_transform_keys`, `ue_set_playback_range`
- **Unlocks:** the verb that turns a static set into a shot — camera moves, animated props, door swings.
  Closing this makes ALL cinematics real. **(This is the item the last review flagged as a deferred
  honest-stub — now with a concrete path.)**
- **API:** `seq.add_possessable(actor)` (proven at `sequencer.py:157`) →
  `binding.add_track(unreal.MovieScene3DTransformTrack)` → section → `section.get_channels()` → `add_key`.
- **Gotcha:** channel type is version-fluid — `MovieSceneScriptingDoubleChannel` in UE5 (large-world
  coords), `FloatChannel` in 4.27. Do NOT hardcode the class — use whatever `get_channels()` returns.

### 6. Parametric layout primitives  ·  `layout.py`  ·  M · high · FEASIBLE
Tools: `ue_array_distribute`, `ue_radial_distribute`, `ue_distribute_along_spline`
- **Unlocks:** grids, rings, runs — colonnade of pillars, ring of standing stones, fence posts down a
  road, a wall from a 4m module ×20.
- **API:** `EditorActorSubsystem.spawn_actor_from_object(static_mesh, location, rotator)` + math/random.
- **Gotcha + LATENT BUG:** the existing `ue_create_cloner` (`mograph.py`) **silently discards its
  count/spacing args** — worth fixing. And the 10s timeout caps discrete spawns at a few hundred;
  beyond that, use ONE HISM/ISM actor with a single `add_instances([...])` batch (one round-trip).

## Tier 3 — Depends-on / bigger lifts

### 7. Procedural camera moves  ·  `cinematics.py`  ·  M · high · FEASIBLE (BLOCKED BY #5)
Tools: `ue_camera_orbit`, `ue_camera_dolly`, `ue_camera_crane`, `ue_camera_path_from_points`
- **Unlocks:** "orbit the village 180° over 8s keeping the well centered", "crane up revealing the
  skyline." Trajectory computed in Python (the bridge's strength), baked as keys.
- **Hard prerequisite:** routes through #5's `add_key` path. Ship #5 and #7 together.

### North-star (L effort, high payoff)
- **Heightfield terrain authoring** — render-target heightmap stamp + sculpt/flatten/ramp (likely/L)
- **Landscape splines** — roads & rivers carved into terrain (likely/L)
- **Surface-aware procedural scatter** — trace-snapped instancing with slope/altitude masking (builds on #1)
- **PCG parameter-drive + generate** — deepen the spawn-only cloner/PCG stubs in `mograph.py`
- **Prefab / Level Instance authoring** — reusable modular groups (Packed Level Actor)
- **Asset import** — FBX/glTF/textures/HDRI from disk; rich asset-registry search ("find meshes that fit")

### Read-side quick wins (S effort — perception the bridge lacks today)
- **Whole-scene gestalt digest** — one call: actor histogram + outliner folders + spatial buckets + level bounds
- **Lighting scene audit** — read back the light state Claude is currently blind to
- **Sequence introspection** — cinematic scene-graph readback
- **Outliner folders / layers / semantic grouping**
- **Batch material assignment** driven by a scene query

## Suggested build order
1. `spatial.py` (#1) — keystone, clones a proven idiom, unblocks set dressing + scatter + terrain.
2. `lighting.py` (#2 + #3) — biggest "wow per call", independent, immediate.
3. Fix the `ue_create_cloner` count/spacing bug, then `layout.py` (#6).
4. Finish `ue_add_keyframe` (#5), then `cinematics.py` camera moves (#7).
5. `materials.py` graph authoring (#4).
6. North-star terrain/scatter/PCG once the spatial + placement base is solid.
